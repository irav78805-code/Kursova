# 🎓 Планувальник розкладу університету (Schedule Planner CLI)

Консольний додаток для ефективного адміністрування навчального процесу, написаний на мові Python із глибоким використанням об'єктно-орієнтованого програмування (ООП). 

Проєкт розроблено в рамках курсової роботи.

## 🚀 Основний функціонал

Система має вбудовану рольову модель (Role-Based Access Control) і підтримує дві ролі з різним рівнем доступу:

### 👨‍🎓 Студент (Режим читання)
- Перегляд загального розкладу на обраний день.
- **Пагінація:** посторінкове виведення великих списків.
- **Пошук за викладачем:** перегляд персонального навантаження фахівця.
- **Фільтр за аудиторією:** перегляд подій у конкретному приміщенні (реалізовано через кастомний ітератор).
- **Пошук вільних аудиторій:** динамічний розрахунок вільних приміщень на заданий час.

### 👨‍💻 Диспетчер (Адміністратор)
- Всі функції Студента.
- **Додавання подій:** лекцій, практичних та іспитів із перевіркою накладок у часі (Collision checking).
- **Видалення подій:** скасування існуючих пар.
- **Експорт звітів (CSV):** генерація табличних звітів для Excel/Google Sheets.
- **Персистентність даних (Pickle):** збереження та завантаження бінарного стану бази даних.

## 🛠 Технологічний стек
- **Мова:** Python 3.10+
- **Архітектура:** OOP (Інкапсуляція, Спадкування, Поліморфізм, Композиція)
- **Спеціальні механізми:** Generators, Iterators, Context Managers, Dataclasses
- **Збереження даних:** `pickle`, `json`, `csv`

## 📁 Структура проєкту
- `main.py` — точка входу, консольний інтерфейс та логіка меню.
- `coursework_core.py` — ядро системи: класи сутностей (`Event`, `Lecture`, `Teacher` тощо) та бізнес-логіка.
- `config.json` — конфігураційний файл (назва закладу, ліміт пагінації).
- `schedule_state.pkl` — бінарний файл збереження бази даних (генерується автоматично).
- `schedule_report.csv` — табличний звіт розкладу (генерується при експорті).
